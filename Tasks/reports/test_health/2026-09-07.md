# Test Health — 2026-09-07

**Verdict:** worse in absolute terms (41 → 68 findings) but **not per test** — `unit` nearly
doubled (1365 → 2687) over the same span, so finding density is roughly flat. Two real
regressions need a decision; the rest is growth.

## Changed since baseline

### Needs a decision (escalated to the user)

- **`tests/integration/presentation/ui` is NOT RUN by default CI and it grew: 37 → 42 tests.**
  `scripts/ci-local.ps1:440` excludes it. A blind spot that gets bigger every time someone adds
  a UI integration test is worse than a fixed one, because the number of promises nobody checks
  keeps rising. Either wire it into `-Full` or stop adding to it.
- **`_ROLE_RENDERS` (C6, new)** — `tests/unit/presentation/ui/test_app_owns_its_size_tokens.py`
  pins 5 `(role, property, pixels)` triples with no completeness guard. It catches a role being
  deleted and is blind to a role being **added** without a pixel assertion, which is the failure
  that actually happens. Not fixed here because the right contract needs a call: *which* roles
  must be pinned? Every `StyleRole` is wrong (most draw no size token); "every role whose QSS
  contains a size property" is scannable from `style.py` and is probably the answer.

### Fixed in this session

- **C3, mine** — `test_re_arming_rebuilds_rather_than_reusing_the_running_engine` promised
  "clean indicator state" in its docstring, which its body cannot check (the engines are
  doubles). Reworded to describe the two facts it does assert.
- **C1** — `test_default_build_buttons_is_an_empty_row` asserted nothing while its **name**
  claimed the row is empty. Now asserts `count() == 0`. (The other new C1s are honest
  `does_not_raise`/`is_a_harmless_no_op` tests — weak, but their names claim only
  exception-freedom, which is what they check.)
- **C7** — four fixtures (`session_state`, `equity_recorder`, `mock_thread_manager`,
  `mock_dispatcher`) were byte-identical in all three Trading Presenter modules. Moved to the
  existing `trading/conftest.py`. Also this session: `fake_container()` in the root conftest
  replaced three hand-rolled DI-container ladders.

### Growth, not regression

- **C7 19 → 32.** Most of the remainder is the legitimate exception the skill names: `view_model`
  (14×), `view` (12×), `presenter` (9×) are the *same name for genuinely different objects* —
  a Settings `view_model` is not a Backtest one. The real subset is the near-copy families
  (`container` 9×, `mock_container` 5×), partly addressed above.
- **C4, new** — `tests/testnet/conftest.py`'s `testnet_credentials` calls `pytest.skip`. This is

- **C1 15 → 23** — tracks suite growth; names are honest per above.

### Good news worth stating
